# Documentação do StableTreasury

Esta pasta guarda o material que ajuda a entender e reproduzir a demonstração.

- [Deep Dive do Depeg Risk Engine](DEEP_DIVE_DEPEG_ENGINE.md): matemática, dados e limites do motor de risco.
- [Glossário](GLOSSARIO.md): termos usados no projeto.
- [ADRs](adr/): decisões de arquitetura e os trade-offs registrados durante a evolução.
- [Specs](spec/): contratos de comportamento que orientaram mudanças relevantes.
- [Validação de mercado](validation/0003-varredura-documental-mercado-e-concorrencia.md): por que a hipótese comercial foi encerrada e o projeto passou a ser uma demonstração técnica.
- [Proveniência dos dados](../reports/proveniencia_stable_treasury.md): fontes, reprodução e limites da série histórica.

Os registros de sessão, hipóteses descartadas e roteiros de trabalho ficaram fora deste repositório público. Eles explicam a evolução interna, mas não são necessários para executar ou avaliar o projeto.
